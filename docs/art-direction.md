# Midnight Diner visual foundation

Approved direction: brighter nighttime diner, teal glass, cherry-red controls, brushed chrome, cream status panel. Moderately stylized 2.5D icons with readable silhouettes. All UI text is live HTML in English.

Artwork generated with the built-in image generation tool. Source PNGs are retained in assets; runtime files are WebP. The atlas is mechanically sliced into individual transparent symbols. The approved reference is docs/approved-concept.png.

Background prompt: Create a production game background using the approved concept as style reference. Remove all game UI, text, logo and symbols. Empty midnight diner interior, bright teal and pink neon, red leather booth left, chrome counter and stools right, rainy windows and warm pendant lights. Refined stylized 2.5D illustration. Decor on the edges, quiet desaturated petrol-blue center. No people or letters.

Symbol prompt: Square transparent atlas, four columns and three rows, eleven isolated symbols in order: Seven, burger, fries, milkshake; coffee, cherries, pie, sundae; jukebox WILD, neon Dollar, marquee Star, empty. Refined hand-painted 2.5D illustration matching the approved concept, clean silhouettes and controlled shading, no photographic micro-detail, no visible grid or backdrop.

The frontend retains artwork provenance and the editable reference; production asset refinement can happen independently of game-state integration.
